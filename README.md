# 🔎 OSINT-BIODATA

**OSINT-BIODATA** is a frontend-based web application designed to help users **organize, document, and manage publicly available information** in a structured bio-data format for legitimate **Open-Source Intelligence (OSINT)** research.

The project is built entirely with **HTML, CSS, and JavaScript**, without requiring any backend, database, or external API.

## ✨ Features

* 👤 Personal & basic information
* 📱 Social media profile information
* 🌐 Website & online profile details
* 📧 Public contact information
* 🗺️ Location-related information
* 🔗 Relationship & connection mapping
* 📝 Investigation notes
* 📋 Structured bio-data sections
* 🎨 Modern and responsive interface
* ⚡ Lightweight frontend architecture
* 🔧 Easy to customize and extend

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive UI
* **JavaScript** — Interactive functionality

## 🎯 Purpose

The purpose of OSINT-BIODATA is to provide a simple interface for **manually organizing information collected from lawful and publicly available sources** during OSINT research.

> ⚠️ This project does not automatically collect personal information, perform unauthorized access, or connect to external data sources.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/OSINT-BIODATA.git
```

Open the project folder and launch:

```text
index.html
```

No server, database, API, or additional installation is required.
